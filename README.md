# Skanda Chittuluru — Analytics Portfolio

A personal portfolio website built with pure HTML, CSS, and JavaScript — no frameworks, no dependencies, just clean and fast.

## 🌐 Live Sections

- **Hero** — Name, tagline, key stats (GPA, Model Accuracy, Projects)
- **About** — Personal bio and professional summary with photo
- **Skills** — Programming, Visualization, Databases, and Specializations
- **Projects** — Tabbed view: Analytical Projects & Excel Projects
- **Experience** — Work history with roles, responsibilities, and tech tags
- **Education** — Northeastern University (MS Analytics) & Lancaster University (BS Business Analytics)
- **Contact** — Phone, Email, LinkedIn, and Resume download

## 📁 File Structure

```
portfolio/
├── index.html       # Main portfolio file (all-in-one)
└── resume.pdf       # Resume file linked in the Contact section
```

> The photo is embedded directly into the HTML as a base64 image, so no external image files are needed.

## 🛠 Tech Stack

| Layer | Technology |
|---|---|
| Markup | HTML5 |
| Styling | CSS3 (Flexbox, Grid, Animations) |
| Interactivity | Vanilla JavaScript |
| Fonts | SF Pro / Helvetica Neue (system fonts) |
| No build tools, no npm, no frameworks |

## ✨ Features

- **Fixed navigation bar** with smooth scroll and active link highlighting
- **Scroll-triggered animations** using IntersectionObserver
- **Project tab switching** between Analytical and Excel project categories
- **Responsive design** — works on desktop, tablet, and mobile
- **Apple-inspired aesthetic** — minimal, clean, high contrast
- **Dark hero & contact sections** with frosted-glass card effects

## 🚀 How to Run

Just open the file in any browser — no server needed:

```bash
# Option 1 — double-click the file in your file explorer

# Option 2 — open from terminal
open index.html          # macOS
start index.html         # Windows
xdg-open index.html      # Linux
```

Or deploy instantly with:
- **GitHub Pages** — push to a repo, enable Pages in settings
- **Netlify** — drag and drop the HTML file
- **Vercel** — connect your GitHub repo
